ELMA BOT PRO 3.0

Contenu :
- main.py : application et interface moderne
- service.py : service Android SMS
- subconscient_elma.json : cerveau/règles/mémoire
- vic_config.json : configuration Gemini + thème
- buildozer.spec : configuration Android
- icone_elma.svg : concept vectoriel de l'identité visuelle triple couleur

Design :
- thème Bleu ELMA par défaut
- thèmes Violet, Vert, Rouge et Sombre
- paramètres de thème sauvegardés
- interface sombre moderne avec cartes et boutons arrondis
- identité ELMA en trois couleurs : bleu, violet et cyan

Règles :
mot-clé | mot-clé => réponse || réponse

Important :
1. Mets ta clé Gemini dans vic_config.json si tu veux l'apprentissage Gemini.
2. Le service SMS Android peut dépendre des restrictions de l'appareil et du rôle d'application SMS par défaut.
3. Avant une version de production, teste la réception/envoi SMS sur le téléphone réel.
